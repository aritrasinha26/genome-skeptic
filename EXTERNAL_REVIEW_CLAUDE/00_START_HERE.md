## What Genome Skeptic is

Genome Skeptic is an **evidence-constrained bacterial genome reasoning system**.

It is not a model that “reads a genome and writes an annotation.” Sequence measurements are produced by deterministic bioinformatics tools. A language model may choose among **registered** follow-up analyses and reason over **already-computed** evidence. A deterministic validator has **final authority** over the scientific endpoint.

### General architecture

```
deterministic measurements
        ↓
   Evidence Ledger
        ↓
   LLM Planner  →  one registered deterministic follow-up action
        ↓
   updated evidence
        ↓
   LLM Critic   →  optional second registered action
        ↓
   deterministic hard validator
        ↓
   final endpoint
```

### Fundamental design rule

**LLMs do not generate sequence measurements.**

Identity, coverage, HMM scores, coordinates, loci, taxonomy, and related quantities are generated by deterministic tools (BLAST+/DIAMOND/MMseqs/HMMER and Genome Skeptic’s own search/locus/family code).

The LLM:

- selects among registered analyses
- reasons over existing evidence
- does not invent identity, coordinates, scores, or loci

The deterministic validator assigns the claim (`target_gene_detected` / `target_gene_not_detected`). Pairwise similarity cannot restore presence after a family-state or domain-only veto.

## The manuscript question (evolved)

The work is **not** primarily “can an LLM annotate genomes?”

The question that the frozen M60 study was designed to answer is:

> **Does adaptive LLM-guided evidence acquisition improve or more efficiently reproduce scientific endpoint decisions relative to the same deterministic core?**

Three Genome Skeptic arms share the same initial measurements, references, endpoint definitions, `TargetMeasurements`, validator, thresholds, and registered actions. They differ **only** in follow-up policy:

| Arm | Follow-up policy |
|---|---|
| GS-Deterministic V4.1 | Fixed mapping from diagnostic needs to one primary registered action |
| GS-Agentic V4.1 (`qwen3:4b`) | Planner chooses ≤1 action; critic may request ≤1 more |
| GS-Exhaustive V4.1 | All eligible registered actions, cheapest first |

External comparators (not Genome Skeptic arms):

- **Conventional**: homology call without falsification / family classifier
- **Specialist**: AMRFinderPlus 4.2.7 (tetA) or NCBI RefSeq/PGAP annotation (rpoB)

AMRFinder did **not** define tetA truth. PGAP did **not** define rpoB truth.

## Prospective result (do not bury this)

The prospective M60 result **did not show increased accuracy**.

On 41 independently truth-evaluable cases:

| System | Exact endpoint correct |
|---|---|
| Conventional | 20 / 41 |
| Specialist comparator (composite) | 34 / 41 |
| GS-Deterministic V4.1 | **33 / 41** |
| GS-Agentic V4.1 (Qwen) | **33 / 41** |
| GS-Exhaustive V4.1 | **33 / 41** |

GS-Agentic vs GS-Deterministic:

- accuracy difference **0.000**
- paired bootstrap 95% CI **0.000–0.000** (10,000 resamples, seed `20260920`)
- corrections **0**, degradations **0**, net **0**
- McNemar **not applicable** because B+C = 0

Using local Qwen, Agentic used **61** follow-up analyses versus **189** under Exhaustive (**67.7% reduction**) with the **same observed** endpoint accuracy. That is not a formal equivalence test.

Qwen wall-clock was **slower** than Exhaustive (median 206.7 s vs 19.4 s) because local LLM inference dominated runtime.

## Claim discipline (non-negotiable)

This package must **not** be read as proving:

- LLM agents improve accuracy
- Genome Skeptic beats specialist tools
- Genome Skeptic is equivalent to specialist tools
- Agentic equals Exhaustive (formal equivalence)
- stronger LLMs never matter
- exhaustive testing is unnecessary generally
- validator limitations are causal unless the 8-case forensics independently support that
- general genome-annotation performance from two endpoints

The current evidence **does** support examination of:

- identical prospective exact-endpoint accuracy of Det / Qwen / Exhaustive on the 41 resolved M60 cases
- lower follow-up action count for Qwen Agentic than Exhaustive
- slower Qwen wall-clock runtime
- Sol changing investigation policy without changing endpoint predictions (post-hoc)
- target-specific performance (including tetA sensitivity **0 / 7**)
- limitations created by unresolved truth
- post-hoc forensic root causes **if** you agree they are justified case by case

## Negative results you must not miss

1. Adaptive follow-up did not change any M60 endpoint versus Deterministic.
2. All **7** independently resolved tetA positives were false negatives for every Genome Skeptic arm (sensitivity 0 / 7). Specialist tetA sensitivity was also 0 / 7. Conventional tetA sensitivity was 1 / 7.
3. rpoB has **zero** independently resolved negatives; rpoB specificity is not estimable.
4. 19 / 60 cases remain `TRUTH_UNCERTAIN` and are excluded from accuracy denominators.
5. Pooled 33 / 41 vs specialist 34 / 41 is a **composite** of two different specialist tools on two different endpoints.

## Provenance caveat (line endings)

Git author dates of the freeze commit are **not** a complete operational clock. Prefer JSON `created_utc` / `hashed_utc` fields, and treat disagreements as a review issue.
